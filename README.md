# Campus Connect

Campus Connect is a college attendance intelligence system with role-based dashboards for Admin, HOD, Teacher, and Student users. It supports attendance marking, parent notification logs, department reports, CSV export, and live dashboard updates through Socket.io.

## Tech Stack

- Frontend: React, Vite, Axios, Socket.io Client
- Backend: Node.js, Express, MySQL, Socket.io
- Auth: JWT role-based access
- Notifications: Gmail SMTP email service with logs and retry flow

## Local Setup

1. Create the MySQL database and tables using your attendance schema.
2. Configure backend environment variables in `backend/.env`:

```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=attendance_db
JWT_SECRET=your_secret
SMS_ENABLED=true
GMAIL_USER=your_gmail_address@gmail.com
GMAIL_PASS=your_gmail_app_password
```

3. Install dependencies:

```bash
cd backend
npm install

cd ../frontend
npm install
```

4. Seed demo data:

```bash
cd backend
npm run seed:demo
```

5. Start the backend:

```bash
cd backend
npm start
```

6. Start the frontend:

```bash
cd frontend
npm run dev
```

Frontend URL:

```text
http://127.0.0.1:5173/
```

Backend API:

```text
http://127.0.0.1:5000/api
```

## Presentation Flow

1. Open Campus Connect and show the branded landing/login screen.
2. Login as Admin and show:
   - Institution dashboard
   - Departments, Classes, Teachers, HODs, Students, Subjects, Timetable
   - Reports and Notification Logs
3. Login as Teacher and show:
   - Teacher dashboard
   - Mark Attendance
   - Reports
4. Submit or edit attendance and point out:
   - Duplicate prevention
   - 30-minute teacher edit window
   - Notification queued count
   - Live dashboard refresh
5. Login as HOD and show:
   - Department-scoped dashboard
   - Department reports
   - Department notification status
6. Login as Student and show:
   - Overall attendance percentage
   - Subject-wise progress
   - Low-attendance warning
   - Recent attendance history

## Notes

- HOD, Teacher, and Student views are scoped by role and department/class ownership.
- Teachers can mark attendance only for assigned subjects.
- Students can only see their own attendance.
- Failed notification logs can be retried by Admin.
- Socket.io is used to refresh dashboards when attendance is marked or updated.

## Gmail Notification Setup

Gmail SMTP is the simplest demo option because it can send to parent email addresses without verifying a custom domain.

1. Open your Google account security settings.
2. Enable 2-Step Verification.
3. Create an app password for Mail.
4. Add these values to `backend/.env`:

```env
SMS_ENABLED=true
GMAIL_USER=kottadadheeraj@gmail.com
GMAIL_PASS=your_16_character_google_app_password
```

`GMAIL_PASS` is not your normal Gmail password. It must be the app password generated by Google.

Campus Connect sends attendance notifications to the guardian email stored in `students.parent_email`.

For real parent alerts, store each guardian email in `students.parent_email`. If your local schema does not have that column yet, add it once:

```sql
ALTER TABLE students ADD COLUMN parent_email VARCHAR(255) NULL AFTER parent_phone;
ALTER TABLE sms_logs MODIFY phone VARCHAR(255) NOT NULL;
```

To test a direct absent notification:

```bash
cd backend
npm run sms:test -- 1 2026-05-15
```
